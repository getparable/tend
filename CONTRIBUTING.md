# Contributing to Tend

Tend is in its bootstrap stage. Start with the first milestone in the README.

Use a feature branch and open a pull request. Explain the behavior being added, how to build and try it, and what you verified. Add tests for execution, scheduling, persistence, and cancellation behavior when those components exist.

The intended implementation languages are Go for the runner and Swift for the macOS app. Keep the first version focused on local task management.

Do not commit credentials, personal task definitions, task output, signing certificates, or provisioning profiles. Use fictional examples in screenshots and fixtures.

Contributions must be compatible with this repository's MIT license. Credit third-party work and preserve its required notices.
